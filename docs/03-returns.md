# Returns and refunds

*Brightway Parcels is a fictional company. This document is test data for the DocChat project.*

## Return window

Customers can return an item within 30 days of delivery. The item must be unused and in its original packaging. Damaged items are not returns: they are handled as damage claims, which have a 14-day limit.

## Return shipping

Return shipping is free for customers in Zone A (Denmark) and Zone B (Sweden, Finland, Norway): a prepaid return label can be printed from the customer portal. Customers in Zone C (all other EU countries) and Zone D (United Kingdom, Switzerland and other non-EU countries in Europe) pay for return shipping themselves, or can buy a Brightway return label for a flat €6.50.

## Items that cannot be returned

- perishable goods, such as food and flowers;
- personalised or engraved items;
- hygiene products, once the seal is opened;
- gift cards.

## Refunds

The warehouse inspects returned items within 7 business days of receiving them. After a successful inspection, the refund goes to the original payment method. The original shipping cost is not refunded, except when the item was wrong or faulty.

## Exchanges

Brightway Parcels does not do direct exchanges. To exchange an item, place a new order and return the original item for a refund.
